# 🌾 AgroBYTE 3.0 — Antes de enviarlo a FIRA

**Este es el paquete candidato de aplicación + código + documentación.** Fue reconstruido directamente a partir del archivo **AGROBYTE PROJECT 2.0.zip** entregado por el equipo.

1. Ejecutamos `INICIAR_AGROBYTE_WINDOWS.bat` (requiere Python y conexión a internet para instalar bibliotecas) o seguimos `README.md`.
2. Confirmamos que «Ejecutar modelo» ofrece la misma predicción que el CSV de 59 filas, que el mapa funciona, que los dos modos de color son legibles y que las descargas contienen los 59 identificadores oficiales.
3. Revisamos `documentacion/REGLAS_FIRA_Y_CONTROL_FINAL.md` y el borrador del informe técnico. Rellenamos contribuciones reales, uso de IA y prompts literales.
4. **Solicitamos confirmación de que FIRA permite hacer públicos los polígonos derivados** antes de desplegar una app abierta al público.
5. Publicamos una URL funcional, grabamos video **máximo cinco minutos** y probamos acceso desde una computadora externa.
6. Solo entonces entregamos en la plataforma FIRA; fecha límite oficial **19/octubre/2026, 23:59 h**.

No se incluye el dataset oficial completo, Git interno del equipo, contraseñas ni datos personales. El modelo no está validado para cualquier parcela, otros ciclos o predicción pre-siembra.
